## Key Points

- Cloudflare announced Cloudflare Wallets, a programmable wallet system designed specifically for AI agents and the agentic Internet
- The system solves two major problems for AI agents: lack of stable identifiers to sign up for APIs and no native payment method for APIs
- There will be two types of wallets: Account Wallets for humans (account owners) and Virtual Wallets for AI agents operating via API keys
- Virtual Wallets allow agents to explore and test APIs autonomously with spending caps and guardrails set by human account owners
- The wallets integrate with Cloudflare's previously announced Monetization Gateway and x402 protocol for micropayments
- Cloudflare is introducing cloudflare.pay identifiers that give agents human-readable, stable identities when interacting with merchants
- This system creates a headless marketplace where AI agents can autonomously discover, test, and purchase APIs and content
- Account owners can set flexible spending policies for agents without requiring constant daily monitoring
- The approach is designed to help build a two-sided agentic market where both buyers (agents) and sellers (merchants) have proper tools
- Users can claim their Cloudflare Wallet handles starting today, with full functionality rolling out soon
