## Key Points

- The Agent Client Protocol (ACP) v2 draft has been released, moving beyond turn-based interactions to support background work and continuous updates
- v2 introduces the ability for sessions to receive updates at any time, not just during user-initiated turns, allowing for real-time updates during background processing
- Messages and tool calls now support uniform patching semantics with stable IDs, enabling streaming, updating, and replacement of content
- The file diff system has been overhauled from oldText/newText to structured file changes supporting add, delete, modify, move, copy operations
- Permission requests are more flexible with custom titles, descriptions, and extensible subjects, not tied to specific tool calls
- v2 includes forward compatibility features by default, allowing extensibility at multiple layers with implementation-specific extensions
- The protocol is currently in draft status and implementers are advised to gate v2 support behind version negotiation and feature flags
- v1 support should be maintained alongside v2 since v1-only peers will remain common for some time
