## Key Points

- Cohere has developed a new serving engine called megakernel that achieves 1.25× to 1.41× faster performance than vLLM for North Mini Code models
- Megakernels fuse the entire forward pass of LLM inference into a single persistent kernel instead of launching separate kernels for each operation
- The approach addresses the memory-bound nature of autoregressive decoding, especially at smaller batch sizes where GPUs spend significant time waiting between kernel launches
- Cohere's implementation reaches 62% of theoretical memory bandwidth speed-of-light at batch size 1, compared to vLLM's 39%
- The system supports continuous batching, paged attention, ragged sequence lengths, and OpenAI-compatible endpoints with tool calling
- Megakernels gain more speedup on MoE models under real traffic because real requests often hit the same experts, leaving more idle time to fill
- The implementation uses a common calling convention (ABI) that makes different operations compatible without requiring a full rewrite
- Performance improvements come from reducing wave quantization, eliminating false dependencies, and enabling weight prefetching between operations
- The serving engine uses a split architecture with Python handling control plane operations and C++ managing the decode loop for maximum performance
- Accuracy tests show the megakernel produces results comparable to vLLM, with no measurable loss of model quality
