## Key Points

- This deep dive tutorial shows how to build an authenticated MCP (Model Context Protocol) server using Cloudflare Workers with OAuth 2.1
- MCP servers allow AI applications like Claude, Gemini, and ChatGPT to connect to external services via standardized tool calls
- The tutorial starts with creating a basic MCP server for a calculator tool that can perform add/subtract/multiply/divide operations
- The article explains the JSON-RPC communication protocol that MCP uses between clients and servers
- When adding authentication, MCP clients (like Claude Desktop) follow OAuth 2.1 protocol when encountering 401 errors
- PropelAuth is used as the OAuth 2.1 compliant authorization server with built-in MCP support
- The tutorial covers implementing Protected Resource Metadata endpoints that tell clients where the authorization server is located
- Token validation is implemented using introspection endpoints to verify user credentials and scopes
- The final implementation requires users to authenticate and consent to specific scopes (like op:add, op:sub) before using MCP tools
- The article demonstrates real-world use cases, like Ahrefs' SEO data MCP server and Google Calendar MCP servers
