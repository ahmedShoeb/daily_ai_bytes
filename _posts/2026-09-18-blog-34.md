## Key Points

- TypeSafe AI is introducing System One Models, a new class of frontier models built specifically for automation rather than chat
- Their first public model is called Jev, optimized for structured outputs and calibrated probabilistic decisions
- Jev achieves similar intelligence levels to existing LLMs on 'System One' tasks but is 40x-200x faster and significantly cheaper
- The model can't hallucinate or make type errors - outputs are always type-safe structured values
- System One Models use Reinforcement Learning for Calibrated Decisions (RLCD) instead of RLHF/RLVR
- Jev uses parallel sampling (generating all outputs in one query) rather than sequential token generation
- Pricing is transparent at $0.042 per million input tokens with free outputs (too cheap to meter)
- End-to-end response time ranges from 70ms-500ms compared to 3-329 seconds for frontier LLMs
- The models always provide calibrated confidence scores with their outputs
- Designed for AI-powered workflows, smart if-statements, and fuzzy decision rules in software
