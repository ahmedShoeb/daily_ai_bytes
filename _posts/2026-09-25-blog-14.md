## Key Points

- Opus 5.5 costs 20% less for input/output tokens and 60% less for cache reads compared to Opus 5
- Task cost depends on four factors: number of turns, cache reads, output tokens (including thinking), and model choice
- Each turn resends the entire conversation, so fewer turns dramatically reduces costs - a 40-turn task costs $1.62 vs $1.02 for 25 turns
- Cache hits can save up to 60% on input costs; 90% cache hit rate reduces costs by 86% compared to no cache
- Opus 5.5 always thinks before replying, and thinking is billed as output tokens (5x the input price)
- Effort levels (low, medium, high, xhigh, max) control thinking depth - higher effort costs more per turn but may save retries
- Use Opus 5.5 for supervised work, Fable 5.1 for unsupervised tasks, and smaller models (Sonnet/Haiku) for lookups
- Changing system prompts or tool definitions clears the cache and triggers expensive rewrites
- Cache lifetime is 5 minutes on API keys vs 1 hour on Claude subscriptions
- Fast mode doubles the price (2.5x speed) - activate at session start to avoid expensive uncached context resends
- Average enterprise developer cost is $13 per active day, with 90% staying under $30 per day
