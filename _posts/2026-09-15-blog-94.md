## Key Points

- OpenAI has achieved near-universal adoption of Codex and ChatGPT Work across all departments, including non-engineering teams like finance, legal, and recruitment, with usage jumping from 0% to 90% in just four months.
- IDE usage has dramatically declined at OpenAI since January as Codex has taken over development workflows, while pull request volume has increased by 10x, creating massive scaling challenges for CI/CD systems.
- OpenAI has built an 'agentic software factory' where AI agents handle most of the development pipeline from code implementation to deployment, with specialized agents performing domain-specific code reviews and 'per-change autonomous SRE' functions.
- The company faces a significant bottleneck with native mobile app deployment, where Apple's and Google's manual review processes create absurd delays in an environment where code can be generated in minutes.
- Codex is transforming engineering practices, with agents now creating monitoring dashboards at a per-change granularity and handling tasks like outage mitigation through Sevbot, OpenAI's internal incident response agent.
- Engineering roles are shifting toward product management and judgment-focused work, with domain experts being embedded in engineering teams to guide AI agents in specialized areas.
- OpenAI has moved all documentation into source code to provide better context for AI agents, and new engineers are directed to ask Codex questions during onboarding because it has comprehensive internal knowledge.
- The Perf Factory system uses agents to monitor production, identify performance issues, and automatically propose fixes, creating a continuous feedback loop into development.
- Threads in Codex are getting dramatically longer, with users spending days on single threads while agents spin off other agents to handle sub-tasks, reducing the management burden on humans.
- Engineering specializations are disappearing at OpenAI, with just 1-2 engineers now able to accomplish previously 'impossible' rewrites and migrations thanks to AI augmentation.
