## Key Points

- Kiro Crew is an AI-powered agent system designed to handle complex engineering workflows that span multiple tools, repos, and sessions
- It addresses the common problem of developers needing to act as 'integration layers' between their own tools, allowing work to continue even when they step away
- The project started as MeshClaw inside Amazon and was used by over 39,000 Amazon builders before being open-sourced
- Kiro Crew features self-learning agents with memory that carries preferences, project context, and history across sessions
- It includes built-in security features like OS-level sandboxing, denied-by-default commands, suspicious-pattern blocking, and credential redaction
- The system orchestrates agents using Agent Client Protocol (ACP) and provides live observability into every step of agent reasoning
- Kiro Crew can run recurring jobs on schedules, handle multi-hour tasks with checkpoints and retries, and coordinate multiple agents working in parallel
- The platform supports purpose-built Apps for specialized workflows like issue triage, work tree management, and task execution
- Kiro Crew is open source with transparent governance through public maintainers and community-driven roadmap planning
- The system works with existing Kiro configurations and integrates with tools like Slack, Telegram, and Discord
