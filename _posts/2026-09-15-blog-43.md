## Key Points

- Aider is a free, Apache 2.0 pair programmer where users manually add files to be changed and it commits every edit to git, while Claude Code is an autonomous agent that searches for files itself and commits only when asked.
- Aider works with almost any model via LiteLLM (including local models through Ollama), while Claude Code is built specifically for Claude models only.
- Claude Code requires a paid Claude plan (Pro at $20/month or Max from $100/month) or an Anthropic API key, while Aider itself is free with only model provider costs.
- Aider's development has stalled - last release was version 0.86.2 on February 12, 2026, with no active maintenance as of September 15, 2026.
- Claude Code supports MCP (Model Context Protocol) servers and has subagents with their own context windows, while Aider doesn't support MCP as of version 0.86.2.
- For version control, Aider commits every change automatically and skips pre-commit hooks by default, while Claude Code snapshots files before each prompt for rollback.
- Alternatives suggested include Claude Code for more autonomy, OpenCode for model flexibility, and cecli (a community fork of Aider) for staying on Aider's codebase with active development.
- Aider's polyglot leaderboard tests models on Exercism exercises but doesn't include Claude Code for comparison.
