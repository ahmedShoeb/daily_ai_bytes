## Key Points

- Kev is a family of small decision models built on Qwen3.5 and Qwen3.8, based on Jev's architecture but open-source and trainable
- Offers four model sizes ranging from 0.8B to 27B parameters for different hardware requirements and accuracy needs
- Provides API compatibility with TypeSafe's System One, making it a drop-in replacement for Jev
- Supports three question types: yes/no (noul), multiple-choice (choice), and rating (score) questions in a single request
- Ships with calibrated probabilities by default using temperature fitting on held-out data
- Includes fine-tuning capabilities with a coding agent skill that runs the entire training loop on Modal
- Can deploy HTTPS endpoints that scale to zero when idle, with one-click deployment commands
- Achieves competitive accuracy, with Kev-27B within one percentage point of Jev on new sources
- Features question isolation where questions share context but cannot read each other's answers
- Includes a playground with interactive demos including chess games and performance testing tools
