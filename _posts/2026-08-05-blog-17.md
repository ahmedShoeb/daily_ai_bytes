## Key Points

SMEvals is a framework for evaluating both small and large language models through systematic testing and grading
The core concept is an 'Eval' - a collection of Tasks used to assess specific capabilities like text-to-SQL or image generation
Evals consist of Tasks (individual exercises), Configs (model setups), Runners (programs that execute tasks), and Graders (scoring systems)
Runs are immutable records of executing a Task against a Config, and can be repeated multiple times to account for non-deterministic results
Grades are produced by applying Graders to Runs, using Checks that can be simple assertions or complex LLM-judged assessments
The framework includes built-in tools for running evals, grading results, generating reports, and serving a live web UI
Evals can be organized into Suites and the system supports both built-in and custom Checkers for flexible evaluation
The architecture supports re-grading runs without re-execution and maintains reproducibility through Grader snapshots
Failed runs (harness-level errors) are distinguished from model performance and excluded from grading and reports
The system provides command-line tools for execution, grading, reporting, and web-based visualization of results
