## Key Points

- Anthropic removed over 80% of Claude Code's system prompt for newer models like Claude Opus 5 and Claude Fable 5 with no measurable loss in coding evaluations
- The company found they were overconstraining Claude Code through system prompts, CLAUDE.md files, and skills, causing conflicting messages
- Newer Claude models have better judgment and can handle decisions without explicit rules, allowing for simpler context engineering
- Instead of giving examples for tool usage, developers should focus on tool design and expressive parameters
- Progressive disclosure is key - moving verification and code review into separate skills that can be loaded when needed
- Tools can use 'deferred loading' where agents search for full definitions only when required
- The command `/doctor` in Claude Code helps rightsize skills and CLAUDE.md files automatically
- Keep CLAUDE.md files lightweight and focused on codebase gotchas rather than obvious information
- Skills should encode specific opinions, knowledge, or best practices particular to teams or products
- References in files like code, mockups, or specs provide clearer instructions than descriptions or screenshots
