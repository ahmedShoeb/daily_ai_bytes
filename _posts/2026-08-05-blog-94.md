## Key Points

MSLK (Meta's Library of Kernels) is an open-source library of fused GPU kernels for transformer workloads including attention, low-precision GEMM, quantization, MoE routing, and convolution
The library provides high-performance GPU acceleration for transformer models with automatic dispatch based on input dtype, hardware architecture, and kernel requirements
MSLK supports multiple GPU architectures including NVIDIA (CUDA) and AMD (ROCm) platforms with specific optimizations for different GPU generations
Key features include fused multi-head attention (fMHA) with various backend implementations (CUTLASS, Flash, CuTe), low-precision matrix operations (FP8, FP4, INT4), and Mixture of Experts (MoE) routing kernels
The library offers both high-level APIs like memory_efficient_attention() and low-level torch.ops.mslk.* operations for direct kernel access
MSLK includes quantization utilities for FP8, MXFP4, MXFP6, and INT4 formats with specialized dequantization and scale management
The documentation provides comprehensive guidance on kernel selection, backend dispatch, scale granularity requirements, and hardware compatibility considerations
Installation is available via PyTorch wheel repositories with different packages for CUDA 13.0+ and ROCm 7.1+ environments
MSLK maintains compatibility with specific PyTorch versions (2.10.x to 2.13.x) and Python versions (3.10-3.14)
