## Key Points

DiffusionGemma is an experimental open-weight language model that uses discrete diffusion to generate text at exceptionally high speeds
Instead of decoding tokens sequentially like autoregressive models, it refines blocks of 256 tokens in parallel to avoid sequential bottlenecks
The model is created by fine-tuning the mixture-of-experts Gemma 4 model with 3.8B activated and 25.2B total parameters
The training uses a compute-efficient two-stage pipeline requiring fewer than 10% of the starting model's total training token budget
First stage uses supervised fine-tuning for bidirectional denoising, second stage combines reinforcement learning with sampler distillation
The model achieves around 20 tokens per forward pass and roughly 1,500 output tokens per second on a single NVIDIA H100 GPU
This is substantially faster than autoregressive models even with state-of-the-art speculative decoding
DiffusionGemma retains support for thinking mode, multimodal inputs, and long contexts from the original model
Despite being diffusion-trained, it can still perform autoregressive generation with only minor performance degradation
The research suggests a potential path toward hybrid diffusion-AR decoding systems
