## Key Points

- Google Cloud's API Gateway can now act as a remote MCP (Model Context Protocol) server, allowing existing REST APIs to be exposed to AI agents and LLMs without rewriting backend services
- MCP is an open standard that enables AI models to discover and invoke functionality in your environment through a standardized protocol
- During Public Preview, API Gateway supports key MCP features including initialization, tool discovery (tools/list), and tool invocation (tools/call)
- The gateway translates MCP JSON-RPC protocol messages into standard HTTP REST requests and vice versa, acting as a proxy between AI systems and existing backends
- MCP configuration is derived directly from OpenAPI 3.x specifications using custom extensions (OpenAPI 2.0 is not supported)
- Limitations include no support for resources, prompts, stdio transport, or streaming/long-running tool calls
- MCP and Model Routing cannot be enabled simultaneously within the same API configuration due to mutual exclusion
- When integrated with API Hub, MCP-enabled gateways are automatically published as MCP servers and appear in Agent Registry for discovery
- The request flow follows a path: AI agent → MCP endpoint → gateway validation → HTTP translation → backend service → response translation → back to client
- Use cases include exposing existing REST APIs as MCP tools, selecting specific operations for agent access, and applying API Gateway security policies to MCP endpoints
