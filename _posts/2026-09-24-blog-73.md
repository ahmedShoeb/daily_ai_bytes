## Key Points

- Devin Cloud is now available directly in your terminal with commands like `devin --cloud`
- Users can create, steer, resume, and watch Devin Cloud sessions from their terminal
- The `/handoff` command allows instant transfer of tasks to Devin to continue working in its own cloud VM
- Cloud sessions outlive the terminal that started them - you can close your laptop and let Devin continue in the background
- Full SSH support for Devin VMs is now available, allowing users to connect to remote development environments
- Users can copy files between VM and local machine using `scp` and launch dev servers with forwarded ports
- The `/handoff` command can also bring cloud work back locally by fetching PR branches and switching Git checkouts
- Free SWE-2 sessions are available from Devin Cloud until October 8
- Users can switch between terminal, web app, and Devin Desktop views with `/open` commands
