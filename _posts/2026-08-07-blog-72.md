## Key Points

- The author measured what Codex sends to AI models by recording requests generated for a 16-character prompt
- A 16-character prompt resulted in a 42,980-byte request, roughly equivalent to 9,435 tokens locally encoded
- Only 0.3% of tokens came from the user prompt; the rest came from Codex's own instructions, tool definitions, and metadata
- Project instructions from AGENTS.md files are transmitted in full based on launch directory hierarchy
- Repository skills initially only send metadata; their actual bodies appear only when explicitly read
- MCP tool descriptions are deferred and only appear after discovery rather than in initial requests
- Files don't automatically appear in requests; they only get added after explicit reads
- Command output stays in history verbatim unless truncated (10,000+ line results get head-tail sampling)
- Images are sent as base64 data URLs, with larger images getting resized and re-encoded before transmission
- When history gets too large, Codex compacts it by sending the history through another request and replacing it with a summary
