## Key Points

- Codex Security is a CLI and TypeScript SDK developed by OpenAI for finding, validating, and fixing security vulnerabilities in code
- The tool requires Node.js 22.13.0 or later, Python 3.10 or later, and access to Codex Security
- Users can install via npm with 'npm install @openai/codex-security' and authenticate via login or API keys
- The tool supports scanning codebases with commands like 'npx @openai/codex-security scan .'
- Multiple scanning options are available including different AI models and effort levels (e.g., '--model gpt-5.6-terra --effort high')
- For CI/CD environments, authentication can be done via environment variables OPENAI_API_KEY or CODEX_API_KEY
- The tool supports both ChatGPT sign-in and API key authentication, with interactive prompts to choose credentials
- Scan history is stored in a workbench state directory, with configurable storage location via CODEX_SECURITY_STATE_DIR environment variable
- The SDK provides TypeScript/JavaScript API for programmatic integration: 'import { CodexSecurity } from "@openai/codex-security"'
- Docker and Docker Compose configurations are available for containerized, noninteractive scanning of Git repositories
