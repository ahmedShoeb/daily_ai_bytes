## Key Points

- The user experimented with Anthropic's Opus 5 model creating a 3D render of Lord of the Rings from the first paragraph using 1M tokens (~$10), resulting in 5500 lines of code over 2 hours
- GPT-4.5 has been released after ~2 years since GPT-4, representing roughly 10X more pretraining compute, but improvements are subtle rather than revolutionary
- GPT-4.5 shows improvements in EQ-related tasks (creativity, humor, analogy-making) rather than IQ/reasoning tasks, which still require reinforcement learning like o1 models
- The attention mechanism was independently invented by Dzmitry Bahdanau for neural machine translation, inspired by how humans look back and forth between source and target text while translating
- Tokenizers are a separate pipeline stage in LLMs with their own training set and algorithm (Byte Pair Encoding), and many LLM quirks trace back to tokenization issues
- A 64-year-old document by Licklider envisioned computing as an intelligence amplification tool, predicting a transient IA period before full AI, though his timeframe estimates were overly optimistic
- The user created microGPT - a GPT implementation in 243 lines of pure Python, demonstrating the core algorithmic content without efficiency optimizations
- The user coded an iOS app in Swift within ~1 hour using ChatGPT assistance despite no prior Swift experience, highlighting LLM-assisted development capabilities
