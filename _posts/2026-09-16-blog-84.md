## Key Points

- Introduces Recurrent Looped Transformer (RLT), a novel architecture that passes decoder's final hidden state to next tokens along with causal encoder representation
- Features sliding-window attention cache at every layer that updates for both prompt and response tokens
- Architecture grows recurrent path with sequence length while maintaining fixed compute per token
- Includes support for reinforcement learning by replaying sampled histories under current parameters
- Experimental results show RLT 6+2 configuration achieves 99.44% accuracy on parity task vs 48.48% for standard Transformer 8
- RLT demonstrates superior performance on tasks like addition and permutation swapping compared to traditional transformers
- Allows sharing of encoder and decoder attention/FFN weights to reduce parameter count
- Supports various training modes: prompt prefill, generation, pretraining, supervised fine-tuning, and RL replay
- Technical report authored by Yifan Zhang, Jichen Feng, and Shihan Qin in September 2026
