## Key Points

- NVIDIA ModelExpress (MX) is a new system designed to accelerate the movement of large model checkpoints (hundreds of GBs to terabytes) across clusters
- MX prioritizes peer-to-peer GPU-to-GPU transfers using RDMA via NVIDIA Inference Xfer Library (NIXL) when compatible weights already exist in serving replicas
- The system can transfer DeepSeek-V4 Pro weights and JIT kernel cache artifacts between serving replicas in under 10 seconds, reducing startup time from 8 minutes to 1 minute 44 seconds
- MX automatically selects the fastest available path: P2P RDMA from serving peers → ModelStreamer → GDS → default loader, with capability-driven fallback
- For the first worker without peers, MX can stream from object storage directly to GPU without landing on disk, or use GPU Direct Storage (GDS) when available
- The system also optimizes kernel compilation inheritance - transferring compiled kernel caches between replicas to avoid repeated JIT compilation
- MX addresses RL post-training workflows where weights change frequently, allowing rollout workers to pull updated weights directly from trainers
- The technology includes memory registration optimizations that reduce tensor registration overhead by 80-99% through pool and VMM arena registration
- MX has native integrations with vLLM and SGLang and supports frameworks including Dynamo and llm-d
- The system collapses cluster downloads so when multiple replicas need the same model, only one downloads from external storage while others reuse cached copies
