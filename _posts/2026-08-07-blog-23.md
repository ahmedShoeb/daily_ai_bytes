## Key Points

- NVIDIA NemotronLabs VoiceChat is an 11B parameter end-to-end, real-time speech full duplex model for conversational AI
- Unlike traditional cascaded systems (ASR → LLM → TTS), this unified architecture enables seamless voice interaction in one model
- Achieves ~450ms turn-taking latency and supports natural barge-in/interruption handling
- First open full-duplex model to support tool calling while maintaining natural conversation flow during tool execution
- Uses a hybrid Mamba/Transformer architecture with Fast Conformer speech encoder, Nemotron Nano v2 LLM backbone, and TTS decoder
- Trained on ~550k hours of audio data from both real speech datasets and synthetic speech generated from text corpora
- Ranks #2 amongst open full-duplex models on VoiceBench benchmark and Full-Duplex-Bench 1.0
- Supports both offline inference for batch testing and interactive streaming for real-time WebSocket conversations
- Requires NVIDIA GPU hardware (A100, H100, H200, B100, B200, or RTX-6000) and runs on Linux systems
