## Key Points

Microsoft confirmed Bing Chat AI chatbot is expanding to non-Microsoft browsers like Google Chrome and Apple Safari
The expansion is currently in testing for select users before broader rollout
Previously, Bing Chat was only available within Microsoft products (Bing mobile app and Edge browser)
Users can access Bing Chat in Chrome by visiting Bing.com and clicking the "Chat" icon
Early reports suggest the Chrome version has limitations compared to Edge version (5 messages per conversation vs 30, 2,000 character limit vs 3,000)
Bing Chat is powered by OpenAI's GPT-4 model
Microsoft is also testing a native dark theme for Bing Chat
The company has been rapidly expanding Bing Chat integration - from mobile apps to Skype and now enterprise versions
Microsoft wouldn't confirm specific details about limitations, global availability, or exact launch timelines
Visual Search feature that responds to uploaded images is also rolling out alongside the expansion
