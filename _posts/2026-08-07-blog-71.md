## Key Points

- OpenAI released ChatGPT Work on July 9th, an agent product for knowledge work that has already crossed 10 million users in three weeks
- ChatGPT Work will merge with regular ChatGPT by the end of 2026, making it the default experience for a billion weekly users
- Work runs on the Codex harness in persistent cloud computers (microVMs) with 8 CPUs, 20GB RAM for Pro accounts and managed Chrome service
- It connects to workplace tools like Slack, email, Drive, calendars, CRMs through plugins and can produce artifacts like sheets, docs, slides, and web apps
- The architecture features persistent storage with synchronized workspaces, but continuity across tasks runs through ChatGPT's product layer rather than direct computer access
- Work shows early signs of proactivity by suggesting personalized tasks generated from user context, though still requires user execution
- Scheduled tasks allow Work to run automations at future times or recurring intervals, either standalone or within existing conversations
- The cloud browser service enables complex workflows like form filling and staying logged into services, though faces some datacenter limitations
- Plugin Directory contains over 1,000 plugins connecting to external services, but discovery remains a weak point
- Key unresolved questions include cloud vs local computer balance, agent sovereignty, and how to teach Chat users to adopt Work's capabilities
