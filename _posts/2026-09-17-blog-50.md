## Key Points

- Cline Desktop is a new open-source desktop application for working with open-weight AI models, expanding from their original VS Code extension
- The app supports 300+ models through Cline provider or local models via ClinePass, and connects to 50+ different providers
- Users can run parallel AI agents simultaneously for different tasks like coding, research, and automation
- The desktop app introduces scheduled tasks (cron jobs) for automating recurring work like PR reviews, vulnerability scanning, and documentation updates
- Cline Desktop allows importing conversations from other coding agents like Claude Code and Codex to continue work with different models
- The app includes web search capabilities for research and voice input for easier instruction giving
- There's a Marketplace for extending functionality with plugins, MCP servers, and skills
- The Mac app is fully open-source like the extension and CLI, using the same underlying Cline harness technology
- Cline Desktop aims to provide a dedicated workspace for managing multiple agent tasks beyond just coding
- The tool is designed to be complementary to existing workflows rather than replacing them entirely
