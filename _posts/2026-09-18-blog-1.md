## Key Points

- Google has released new Gemini Live models: Gemini 3.8 Live and 3.8 Live Extended Thinking for building real-time voice-first applications
- Gemini 3.8 Live Extended Thinking ranks #1 on Artificial Analysis' Speech-to-Speech leaderboard for complex tasks
- Gemini 3.5 Transcribe provides highly precise transcription across 85+ languages with low-latency
- The new models feature asynchronous function calling - they can execute API/tool calls in background while streaming audio responses
- Models support visual context integration, allowing voice agents to understand both what users say and see
- Gemini 3.8 Live models offer alphanumeric precision for parsing codes/numbers, multilingual support for 97+ languages, and incremental content updates
- Gemini 3.5 Transcribe achieves Word Error Rates of 4.0% (streaming) and 2.6% (non-streaming)
- Developers can access additional audio tools: Gemini 3.5 Live Translate for speech-to-speech translation, Gemini 3.1 Flash TTS for speech generation, and Lyria 3.5 for music generation
- Google provides comprehensive developer tools including Google AI Studio, GitHub examples, and API access
