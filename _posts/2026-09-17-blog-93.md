## Key Points

- iOS 27 and macOS Golden Gate private frameworks reveal Apple has designed Siri architecture to work with third-party AI models at a deep level
- A mechanism called Model Delegation allows Claude to appear as a Siri extension similar to existing ChatGPT integration
- In demonstrations, users can choose Claude as AI model via contextual menu and Claude can handle Siri tasks like setting reminders in Apple's Reminders app
- Claude can perform tasks Siri cannot handle, like creating CSV files, and return results through Siri interface
- Second protocol in Model Manager Services allows Apple's server-side Siri model to be completely replaced by models like GPT-5.6
- When replaced, ChatGPT receives Apple's Siri planner prompt and tool definitions, enabling it to request system actions and use personal data
- In one demo, ChatGPT model within Siri app can find emails about specific topics, summarize contents, and send messages via Messages app
- European Union's Digital Markets Act may have influenced Apple's approach by requiring third-party access to iOS features including Siri
- The "Ask..." implementation is currently limited to ChatGPT extension in macOS Golden Gate Release Candidate
- Apple has not yet opened up model delegation entitlement to third parties but shows extensive engineering for future model interoperability
