## Key Points

- DiffusionGemma is an experimental open-weight language model that uses discrete diffusion for exceptionally fast text generation
- Instead of decoding tokens sequentially like autoregressive models, it refines 256-token blocks in parallel, avoiding the sequential bottleneck
- Created by fine-tuning the mixture-of-experts Gemma 4 model with 3.8B activated parameters and 25.2B total parameters
- Achieves compute-efficient training using less than 10% of the starting AR model's total training token budget
- Employs a two-stage training pipeline: supervised fine-tuning for bidirectional denoising, then reinforcement learning with sampler distillation
- Generates around 20 tokens per forward pass and achieves roughly 1,500 output tokens per second on a single NVIDIA H100 GPU
- Maintains support for thinking mode, multimodal inputs, and long contexts despite diffusion fine-tuning
- Retains capability for AR generation with only minor performance degradation, suggesting potential for hybrid diffusion-AR decoding
- Sets a new Pareto frontier for balancing generation speed and model capability
- Substantially faster than even state-of-the-art autoregressive models with speculative decoding
