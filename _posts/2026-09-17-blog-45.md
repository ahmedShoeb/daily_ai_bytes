## Key Points

- Tau is a terminal-based coding agent from HuggingFace that helps developers by reading files, editing code, running commands, and maintaining session history
- It's designed as both a practical tool and a teaching project to demonstrate how coding-agent systems are built
- Users interact with Tau by typing requests like 'explain this repo', 'add tests', or 'fix this stack trace' directly in their terminal
- The architecture is structured into three layers: tau_ai (provider abstraction), tau_agent (core brain and session management), and tau_coding (application layer with CLI and tools)
- Tau supports multiple AI providers including OpenAI, Anthropic, Hugging Face, OpenRouter, and custom endpoints
- It features durable session management with JSONL storage, allowing users to resume and branch conversations
- The tool is designed with separation of concerns - the core harness doesn't depend on the UI layer, making it portable for different frontends
- Tau is available through multiple installation methods including curl scripts, package managers, and from source, requiring Python 3.12+
- It includes built-in coding tools (read, write, edit, bash), slash commands, and project instruction support from configuration files
- The project is actively maintained, open source under MIT License, and designed for readability and extensibility
