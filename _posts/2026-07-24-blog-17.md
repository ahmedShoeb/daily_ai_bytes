## Key Points

- Laguna S 2.1 is a 118B total parameter Mixture-of-Experts model from Poolside with ~8B activated parameters per token
- It's designed specifically for agentic coding and long-horizon work, sitting between Laguna XS 2.1 and Laguna M.1 in the Laguna series
- Features a massive 1,048,576-token context window and mixed sliding-window/global attention layout (12 global attention layers, 36 sliding-window layers)
- Includes native reasoning support with interleaved thinking between tool calls, controllable via `enable_thinking` parameter
- Supports speculative decoding with a trained DFlash draft model for lower-latency serving
- Available in multiple quantized variants including FP8, NVFP4, INT4 and GGUF formats
- Uses the OpenMDW-1.1 license allowing commercial and non-commercial use
- Benchmark results show strong performance: 70.2% on Terminal-Bench 2.1, 78.5% on SWE-bench Multilingual, and 59.4% on SWE-Bench Pro
- Compatible with multiple inference engines including vLLM, SGLang, Transformers, TRT-LLM, and llama.cpp
- The model has 256 routed experts (top-10) plus 1 shared expert, with grouped-query attention and per-head softplus output gating
