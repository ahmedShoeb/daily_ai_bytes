## Key Points

- Google Cloud API Gateway now offers model routing in Public Preview, allowing developers to dynamically route AI requests without hardcoding endpoints
- The system accepts OpenAI-compatible requests and can route them to Gemini, Claude, or OpenAI OSS-GPT models
- API Gateway provides a lightweight, serverless ingress layer that handles dynamic routing between different AI models
- Developers can use API Gateway standalone for rate limiting and token tracking, or integrate it with Gemini Enterprise Agent Platform for security governance
- Model routing configuration uses OpenAPI 3.x specifications with x-google-api-management extension blocks to define routing logic
- The system requires all backends referenced by a single router to share the same host (like aiplatform.googleapis.com)
- Example configurations show routing between Gemini and Claude models, and between OpenAI GPT and Gemini models
- Applications simply send standard OpenAI POST requests to specific endpoints, and the gateway handles payload transcoding and routing
- The system is designed to help developers stop managing proxies and unify their AI traffic management
