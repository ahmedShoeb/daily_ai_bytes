## Key Points

- DAPO is a fully open-sourced system for large-scale LLM reinforcement learning that achieves state-of-the-art performance
- The system includes algorithm, code infrastructure, and dataset for scalable RL research
- DAPO achieves 50 points on AIME 2024 based on the Qwen2.5-32B base model
- It outperforms previous state-of-the-art DeepSeek-R1-Zero-Qwen-32B with 50% fewer training steps
- The repository provides model weights for DAPO-Qwen-32B trained using the DAPO algorithm
- Includes training and validation datasets: DAPO-Math-17k for training and AIME 2024 for validation
- The team provides scripts for reproducing both partial (44 points on AIME 2024) and full (50 points on AIME 2024) implementations
- Training stability metrics show steady length growth, stable reward scores, and controlled entropy balance between exploration and exploitation
- The system is built on top of the verl framework and experiments were conducted on Volcano Engine Machine Learning Platform
- Recent updates include training records and checkpoints achieving 50%+ on AIME 2024 with evaluation instructions
