## Key Points

- OpenCodex is a lightweight local proxy that translates Codex's Responses API to work with any language model provider
- It allows developers to use Claude, Gemini, Grok, GLM, DeepSeek, Kimi, Qwen, Ollama, or any other LLM with OpenAI Codex and Claude Code workflows
- The tool manages ChatGPT account pools for Codex auth, automatically routing new sessions to the lowest-usage healthy account
- Provides OAuth support for xAI, Anthropic, and Kimi - allowing login with existing accounts without API keys
- Works with Codex CLI, App, SDK, GitHub Copilot App, and Claude Code through protocol adapters
- Includes a web dashboard for managing providers, OAuth status, model selection, and live request monitoring
- Can be installed as a system service on macOS (launchd), Linux (systemd), and Windows (Task Scheduler)
- Supports over 40 built-in providers plus custom OpenAI-compatible endpoints
- Features history-safe injection that preserves chat history and clean exit with zero residue
- Has experimental Cursor adapter support with live HTTP/2 transport and executor hooks for MCP, screen recording, and computer-use features
