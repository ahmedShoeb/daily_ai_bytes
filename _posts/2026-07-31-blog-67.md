## Key Points

- Gemini 3.6 Flash is now the default model for managed agents in the Gemini API, providing balanced capabilities for reasoning, coding, and tool use
- Developers can now explicitly select different models including Gemini 3.5 Flash-Lite for lower cost or pin to their preferred model
- New environment hooks feature allows custom scripts to run before or after every tool call inside the sandbox, enabling validation pipelines
- Hooks support both command-line scripts and HTTP endpoints, with regex pattern matching for targeting specific tools
- Managed agents are now available on free tier projects without requiring active billing
- Budget controls with max_total_tokens parameter prevent runaway tasks by safely pausing execution when limits are reached
- New scheduled execution feature automates recurring agent tasks using cron schedules
- Environments API allows programmatic management of sandbox sessions including listing, inspection, and deletion
- The antigravity-preview-05-2026 agent now runs Gemini 3.6 Flash by default with no code changes required
- Teams are already using hooks for production-grade workflows, like OffDeal's automated image verification system for investment banking decks
