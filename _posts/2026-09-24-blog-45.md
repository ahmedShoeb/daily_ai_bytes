## Key Points

AWS released its Strands harness, a ready-to-run agent framework that can search the web, run commands, edit files, remember past work, and delegate tasks to helper agents
The harness supports models from Amazon Bedrock, Anthropic, OpenAI, Google, and local Ollama models, but leaves the intelligence/brains for developers to choose
AWS claims Strands harness costs 26% less than competitors using the same models across seven benchmarks, and 77% less than Claude Code in one Fable 5 evaluation
The agent maintains long-term memory across runs, manages its own context window to control costs, and handles multi-step work with checklists
Designed for three workload families: operations/DevOps automation, back-office process automation, and conversational experiences inside products
AWS faced challenges with context management and balancing tested defaults with developer customization, ultimately exposing all defaults in regular code
Includes a CLI for natural language prototyping and can run on laptops, CI pipelines, private servers, or cloud deployments without requiring AWS infrastructure
Available through PyPI, npm, and CLI, requiring only runtime and connected tools/services from developers
