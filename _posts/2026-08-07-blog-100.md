## Key Points

- ChatGPT Work is OpenAI's agent product for knowledge work that reached 10 million users in three weeks and will merge with ChatGPT by year-end
- The agent connects to work tools (Slack, email, Drive, calendars, CRMs) and uses a cloud computer with persistent storage synchronized across microVMs
- Work offers two modes: cloud (synchronized across devices) and local (runs directly on your computer, similar to Codex)
- The agent has broad freedom within a task but continuity across tasks runs through ChatGPT's product layer rather than the computer itself
- Work provides hints of proactivity by suggesting personalized tasks generated from user context, like preparing for upcoming meetings
- Scheduled tasks allow automation at future times or on recurring schedules, with two types: standalone tasks and conversation heartbeats
- Browser use is enhanced through a separately hosted Chrome service that maintains persistent profiles and logged-in sessions
- Work uses plugins as the primary way to connect to external apps and services, with over 1,000 plugins available in the directory
- Memory is managed externally through ChatGPT's synthesized user profile, not within the agent's workspace
- The article explores tensions OpenAI needs to resolve before merging Work with ChatGPT for a billion users
