## Key Points

- Google Cloud API Gateway now offers model routing in Public Preview, providing a lightweight serverless ingress layer
- The system accepts OpenAI-compatible requests and dynamically routes them to Gemini, Claude, or OpenAI OSS-GPT models
- Developers no longer need to hardcode endpoints or manage open-source proxies when building AI applications
- API Gateway can be used standalone for rate limiting and token tracking, or integrated with Gemini Enterprise Agent Platform
- The setup process involves configuring routing logic through OpenAPI specs, deploying the gateway, and sending standard requests
- All backends referenced by a single router must share the same host (like aiplatform.googleapis.com)
- Model routing selects different models and paths on a shared Vertex host rather than routing across different hosts
- Example endpoints include /v1/chat/gemini-claude (defaults to Gemini with Claude option) and /v1/chat/openai-gemini (defaults to OpenAI with Gemini option)
- The Gateway intercepts requests, transcodes payloads to native backend schemas, and routes them dynamically
- Model routing is designed to give developers freedom to choose the best AI model for each task without infrastructure overhead
