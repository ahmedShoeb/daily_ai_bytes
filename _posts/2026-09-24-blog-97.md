## Key Points

- Aikido introduces Altar, their first open-weight security model designed for sovereign security intelligence that runs inside customer infrastructure
- Altar provides advanced AI security capabilities without sending sensitive data to third-party inference services
- The model is built on GLM-5.3 and reduces from 1.51 TB to 328 GB using expert pruning and quantization
- Altar maintains 92% of the parent model's vulnerability coverage with 33% less storage
- The model identified a critical-severity vulnerability during a client production pentest shortly after deployment
- Aikido addresses the 'deployment gap' by making frontier-grade models efficient to operate for specific security workloads
- The company uses Cerebras REAP pruning technique to preserve cybersecurity, coding, and language capabilities
- Altar can be deployed using a 4-H200s node with vLLM and is available under Aikido's organization
- The approach enables security intelligence to run inside any environment it protects, including air-gapped networks
- Future work includes exploring lower-bit formats, fine-tuning for security workflows, and building self-learning pipelines
