## Key Points

Smevals is a framework for running evaluations against both small and large AI models
The framework revolves around three main concepts: Evals (collections of Tasks), Configs (model setups), and Runs (execution records)
Evals consist of directories containing eval.yaml files, tasks, configs, graders, and custom checkers
Tasks are individual exercises that models must complete, each with prompts or other inputs
Configs define the model setup including system prompts, tools, and model parameters
Runs are immutable records of executing one Task against one Config using a Runner
Graders evaluate Runs by applying sequences of Checks to produce Grades with scores and metrics
Checkers are reusable programs that implement specific validation operations on model outputs
The framework includes command-line tools for running evals, grading results, generating reports, and serving web interfaces
Smevals supports both built-in checkers and custom checkers written by users
