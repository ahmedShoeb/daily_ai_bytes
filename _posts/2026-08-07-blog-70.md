## Key Points

- Kiro Crew is an AI agent platform designed to handle engineering work that spans multiple tools, sessions, and days, acting as an integration layer between tools to keep work moving even when developers step away
- Originally developed internally at Amazon as 'MeshClaw', it has been adopted by over 39,000 Amazon builders with nearly 500 contributors shipping 597 updates
- Kiro Crew coordinates work across sessions including investigating incidents across repos, running multi-hour migrations, and handling recurring jobs like morning updates that check PRs and fix flaky tests
- The platform features defense-in-depth security with OS-level sandboxing, denied-by-default commands, suspicious-pattern blocking, credential redaction, and signed audit logs
- It provides full observability of AI agent reasoning and actions through the Agent Client Protocol (ACP) with live activity views showing planning, parallel sub-agents, and tool calls
- Kiro Crew supports running agents locally or remotely, integrates with tools like Slack, Telegram, and Discord, and includes 'Apps' - purpose-built interfaces for automating workday tasks
- Agents are self-learning with memory that carries context between sessions, allowing corrections to become durable lessons and repeated patterns to become reusable skills
- The platform is now open source with transparent governance through a public steering committee and decision-making documented in the GitHub repository
- Kiro Crew runs on the existing Kiro CLI and reads .kiro configuration files, requiring no extra setup for existing Kiro users
- The release includes several built-in Apps like DevFleets for work tree management, Task Runner for long-running tasks, and Issue Radar for triaging issues and PRs
