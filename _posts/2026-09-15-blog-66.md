## Key Points

- pnpm v12.4.0+ can install Python dependencies alongside npm packages in a single `pnpm install` command
- Multi-ecosystem support is experimental and may change, but allows shared connection budget, credentials, and content-addressable store
- Python dependencies are enabled in `pnpm-workspace.yaml` by setting `python.enabled: true`
- pnpm reads `pyproject.toml`, writes `pylock.toml`, and creates virtual environments for each project
- Python packages are added using the `pypi:` prefix (e.g., `pnpm add pypi:httpx`)
- Each project gets a `.venv` symlink to `.pnpm/python-envs/` for atomic environment swaps
- Existing manually created `.venv` directories are preserved and not overwritten
- `pnpm run` and `pnpm exec` automatically add the virtual environment's script directory to PATH
- Python resolution semantics are kept separate from npm/Cargo, sharing only underlying plumbing
- Standard pnpm flags like `--lockfile-only`, `--frozen-lockfile`, and `--offline` work with Python dependencies too
