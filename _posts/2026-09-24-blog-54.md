## Key Points

- RecreationWorld is a five-platform framework for studying hybrid computer-use agents that autonomously interleave GUI exploration, coding implementation, and visual verification
- It provides 250 held-out tasks with programmatic and visual evaluation through RecreationBench
- The framework transforms open-source applications into scalable, verifiable training experience
- Agents operate in an explore–implement–verify loop rather than fixed stages, with access to both GUI-control and software-development tools
- Scoring depends on observable behavior rather than source-level similarity, allowing different languages, frameworks, and architectures
- The framework supports five platforms: Ubuntu, macOS, Windows, Android, and Web (50 tasks each)
- GPT-6 Astra currently leads performance with 58.06% average score, followed by Claude Opus 5 at 44.16%
- Evaluation includes both programmatic (Prog) and visual language model (VLM) scoring methods
- The project is open-source under MIT License and has an associated arXiv paper from 2026
- Framework allows agents to build and launch their own candidates, inspect results, and revise implementations
