## Key Points

- Perplexity has launched Portable Computer, a local version of its AI agent that runs on Windows PCs with compatible NVIDIA GeForce RTX and RTX PRO Workstations
- The system keeps sensitive information on-device and uses local models to analyze data across files without consuming cloud credits
- Portable Computer uses optimized local models like Qwen 3.8 27B that are post-trained to work with Perplexity's Computer system
- The AI agent can identify when tasks need cloud support and asks for user permission before sending information off-device
- It connects with popular apps including Microsoft Outlook, OneDrive, Word, Google Drive, Gmail, Slack and GitHub
- Practical applications include engineering (GitHub pull request analysis), finance (portfolio optimization), and startups (user activation analysis)
- Available for NVIDIA GPUs with 24GB or more VRAM, with NVIDIA DGX Station support coming soon
- The release builds on existing support for NVIDIA DGX Spark systems and RTX PCs running Linux
- Portable Computer simplifies local AI setup by eliminating the need for users to research models or configure complex software stacks
