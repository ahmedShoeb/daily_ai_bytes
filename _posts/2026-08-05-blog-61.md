## Key Points

- Google is working to narrow the feature gap between the Gemini desktop app and its web counterpart
- Dedicated tabs for image and video generation are being added to the desktop app's navigation
- A camera attachment feature is in development, allowing users to take pictures directly into prompts (similar to mobile functionality)
- Gemini Spark now includes an option to add custom MCP servers in its desktop connectors menu
- These features are currently in trusted-tester builds with no public rollout date announced
- The improvements follow a busy month for Gemini that included Spark reaching macOS on July 1
- Screen-aware reasoning and intelligent dictation features began rolling out on July 29
- These changes aim to reduce the need for users to open the browser version of Gemini
