## Key Points

- DeepSeek-V4-Flash-0731 is the official release that supersedes the preview version with substantially enhanced agentic capabilities
- The model features the same structure as DeepSeek-V4-Flash-DSpark and includes a speculative decoding module
- It outperforms DeepSeek-V4-Pro (Preview) on multiple benchmarks despite having far fewer activated parameters
- The model is broadly competitive with the strongest proprietary models currently available
- It introduces three reasoning effort levels (low, high, max) that control how much deliberation the model spends before answering
- Supports OpenAI-compatible API format for easier integration
- Can be run with vLLM and SGLang for inference, with specific configurations for DSpark speculative decoding
- Recommended sampling parameters include temperature=1.0 with top_p=0.95 for agentic scenarios
