## Key Points

- NVIDIA NemotronLabs VoiceChat is an 11B parameter end-to-end, real-time speech full-duplex model for conversational AI
- Unlike traditional cascaded systems (ASR → LLM → TTS), this unified architecture eliminates multiple models or API handoffs, reducing latency
- The model achieves impressive ~450ms response time for natural turn-taking and supports real-time interruption/barge-in capabilities
- It's the first open full-duplex model to support tool calling while maintaining natural conversation flow during tool execution
- The model uses a hybrid architecture: Fast Conformer Speech Encoder, Nemotron Nano V2 9B LLM backbone, and TTS decoder with separate tool-calling channel
- Trained on approximately 550k hours of audio data including real speech datasets and synthetic speech generated from various TTS systems
- Benchmarks show #2 ranking among open full-duplex models on VoiceBench and Full-Duplex-Bench 1.0
- Supports function calling with specialized prompts that require ASCII-only, TTS-friendly tool responses
- Released under OpenMDW License Agreement version 1.1 for research purposes only
- Requires NVIDIA GPU hardware (A100, H100, H200, B100, B200, RTX-6000) and Linux operating system
